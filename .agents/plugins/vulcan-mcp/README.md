# Maptek Vulcan MCP Plugin

Plugin oficial de Antigravity para la integración con **Maptek Vulcan 12 Desktop**.

## Contenido del Plugin
* **Servidor MCP**: Configurado en `mcp_config.json` para ejecución con `uv`.
* **Agente Personalizado**: `mining-geologist` (Ingeniero Geólogo y Especialista Minero).
* **Skills**:
  * `vulcan-workflow`: Procedimientos paso a paso para auditoría, bloques y sondajes.
  * `vulcan-file-formats`: Referencia oficial de tipos de archivos de Vulcan (`.bmf`, `.00t`, `.dgd.isis`, `.dhd.isis`, `.scd`, `.grid`).
  * `vulcan-python-sdk`: Referencia técnica de `maptek.vulcan`, `maptek.vulcan_gui` y `mapteksdk 2.0`.
* **Hooks**: `hooks.json` (Verificación del listener en `127.0.0.1:9877`).
* **Reglas**: `rules/AGENTS.md` (Pautas de interacción y buenas prácticas).
