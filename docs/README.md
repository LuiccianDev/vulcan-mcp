# Documentación Técnica: Maptek Vulcan & Python SDK

Esta carpeta concentra la referencia técnica extraída de la documentación oficial de **Maptek Vulcan Help**, **Maptek Python SDK 2.0** y la introspección directa del SDK embebido en **Maptek Vulcan 12 Desktop**.

## Índice de Documentos

1. **[Formatos de Archivo de Vulcan (`VULCAN_FILE_FORMATS.md`)](./VULCAN_FILE_FORMATS.md)**
   * Especificación de archivos `.bmf`, `.00t`, `.dgd.isis`, `.dhd.isis`, `.scd`, `.grid`, `.isix` y `.wrk`.
   * Estructura interna de tablas y correspondencia con las herramientas de Vulcan MCP.

2. **[Referencia de Maptek Python SDK (`MAPTEK_PYTHON_SDK.md`)](./MAPTEK_PYTHON_SDK.md)**
   * Catálogo completo de clases y métodos de `maptek.vulcan` y `maptek.vulcan_gui` (Python 3.5.2 embebido).
   * Guía y equivalencias con **Maptek Python SDK 2.0** (`mapteksdk.project`, `mapteksdk.data`).
   * Ejemplos cortos y certeros de código listos para ejecutar.
